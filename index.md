## Project Showcase



### CSI 300 Index Return Analysis

**Research Question:** How has the CSI 300 performed over 2021–2025 in terms of returns, volatility, and drawdown? Does the return distribution follow a normal distribution?

**Status:** ✅ Completed

**Key Visualization — Daily Return Distribution:**

![Daily Return Distribution](https://raw.githubusercontent.com/[your-github-username]/data-science-project/main/figures/daily_returns_histogram.png)

**Findings:**

- The average daily log return is slightly negative (~ -0.02%), consistent with a prolonged sideways market.
- Annualized volatility is approximately 19%, with clear spikes during the 2022 downturn.
- The return distribution exhibits **fat tails** — extreme daily moves occur more frequently than a normal distribution would predict.
