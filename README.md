## How It Works

This site is built using **GitHub Pages** with Jekyll (default Markdown rendering):

1. Push `index.md` to the `main` branch root folder.
2. Go to **Settings → Pages**.
3. Under *Build and deployment*, select **Deploy from a branch**.
4. Choose branch: `main` / folder: `(root)`.
5. Save and wait 1–2 minutes for the site to deploy.
